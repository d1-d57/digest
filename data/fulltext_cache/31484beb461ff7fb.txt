                                                   Abstract. Larson’s problem [17, Problem 3] asks “Must the support
                                                   of the Fourier transform of a wavelet contain a wavelet set?". We give
                                                   an affirmative answer to a non-measurable variant of this question by
                                                   proving that the Fourier transform of a wavelet must contain a possibly
                                                   non-measurable wavelet set. We also provide background results on
                                                   Larson’s problem and propose two new related problems.




                                                                             1. Introduction
                                              In the early 1990’s, groups led by David Larson and Guido Weiss were
                                           studying the mathematical underpinnings of wavelets. As would be expected,
                                           the two groups came up with different terms for objects that were of fun-
                                           damental interest in their investigations. One such example is a wavelet
                                           with the property that its Fourier transform (i.e. frequency) is the indicator
                                           function of a set. Larson focused on the frequency support of the wavelets,
                                           and called the frequency support of such wavelets wavelet sets [6, 7]. Weiss
                                           focused on wavelets whose modulus of the frequency is the indicator func-
                                           tion of a set, and called such wavelets mimimally supported frequency (MSF)
                                           wavelets [10, 19]. The reasoning behind Weiss’ nomenclature is that mini-
                                           mally supported wavelets have support with the smallest possible Lebesgue
                                           measure.1 In the middle of 1990’s, Larson asked whether minimally sup-
                                           ported wavelets are also minimally supported with respect to set inclusion
                                           [17]. That is, if ψ is a wavelet whose Fourier transform has support E, and
                                           ψ is not an MSF wavelet, is there a set F ⊂ E with the Lebesgue measure
                                           of E \ F positive and such that F is the support of the Fourier transform of
                                           a wavelet? The most natural way to prove that MSF wavelets are minimally
                                           supported with respect to set inclusion would be to show that the support
                                           of the Fourier transform of a wavelet must contain a wavelet set. This was
                                           formalized as an open problem in [17].
                                           Problem 1.1. Must the support of the Fourier transform of a wavelet con-
                                           tain a wavelet set?
                                             The motivation for this problem (in addition to the nomenclature pre-
                                           sented above) is two-fold. First, Larson had a program for using operator

theory to build more complicated wavelets from simpler wavelets. In par-
ticular, Larson, together with Dai, had an operator theoretic approach to
constructing the Lemarie-Meyer wavelets from wavelet sets [6]. Their con-
struction is similar in spirit to the construction presented in [10]. Larson and
Dai also proved that operator theoretic techniques could be used on more
complicated families of wavelet sets to build more general wavelets. A nat-
ural question is whether every wavelet can be built using these techniques.
However, since the techniques always produce a wavelet whose frequency sup-
port is contained in the union of the underlying wavelet sets and contains a
wavelet set, a necessary condition to be able to construct every wavelet this
way would be a positive solution to Problem 1.1.
    The second motivation came later, and is also more tenuous. It is easy to
see that if π is a rotation on the plane, then there exists an S = Sπ ⊂ R2 such
that S tiles R2 via translations along π(Z2 ). The Steinhaus tiling problem
asks whether there exists a set S ⊂ R2 such that for every rotation π, S
tiles R2 when translated by the elements of π(Z2 ). The Steinhaus problem
was solved in [14, 15], where a non-measurable set S was constructed. It
remains an open problem whether a measurable Steinhaus set in R2 can be
constructed. For a higher dimensional variant of Steinhaus problem, see [8].
    Similarly, we will see below in Proposition 2.10 that if E is the support
of a wavelet, E must contain a subset which tiles by translations along Z
and a different subset which tiles by dilations of powers of 2. Problem 1.1
asks whether there is a single set which does these simultaneously. In the
Steinhaus tiling problem and Problem 1.1, we are asking to find a single
set which tiles via multiple actions. The differences are many: the Steinhaus
problem has uncountably many tilings, while we only have two, the Steinhaus
problem only considers translational tilings while our tilings are more diverse,
and our problem considers the relationship between functional tilings and set
tilings.
    It is worth mentioning two other similar works on simultaneous tilings.
Han and Wang [9] showed that simultaneous translational tiling by two lat-
tices of the same volume always exists. Kolountzakis and Papageorgiou [16]
studied simultaneous functional tilings with respect to a collection of lattices.
    The main result in this paper shows that a possibly non-measurable wave-
let set exists in the support of the Fourier transform of any wavelet. The
proof relies on a result of Isbell [12, 13] on the existence of a positive diagonal
of a doubly stochastic matrix. The original Larson’s problem, whether such
a set can be chosen to be measurable, remains open.

  In order to construct an example that illustrates the additional geometric

has measure zero whenever k ̸= k ′ are integers.
Theorem 2.5. [11] Let F be a measurable subset of R. Then, F is a subset
of a wavelet set if and only if
    (1) F packs by translations,
    (2) F packs by dilations,
    (3) there exists a measurable set U ⊃ F such that U packs by translations
        and U tiles by dilations, and
    (4) there exists a measurable set V ⊃ F such that V packs by dilations
        and V tiles by translations.
Moreover, if the four conditions are met, then the wavelet set can be chosen
to be a subset of U ∪ V .

Lemma 3.6. If U and V are measurable subsets of R such that m(U ) =
m(V ) = c1 and ν(U ) ≤ c2 ≤ ν(V ), then there exists a set W ⊂ U ∪ V such
that m(W ) = c1 and ν(W ) = c2 , where 0 ≤ ci < ∞.
Proof. Without loss of generality, we can assume that ν(V ) < ∞. In fact,
if ν(V ) = ∞, then for every ϵ > 0, ν(V ∩ [−ϵ, ϵ]) = ∞. Choose ϵ > 0 such
that ν(V \ [−ϵ, ϵ]) > 1 and let V1 = V \ [−ϵ, ϵ]. Note that
               m(U \ V1 ) ≥ m(V ) − m(V1 ) = m(V ∩ [−ϵ, ϵ]).
Hence, there exists a subset V2 of U \ V1 of measure m(V ∩ [−ϵ, ϵ]). Once
the lemma is proven for U and V1 ∪ V2 , then it also holds for the original U
and V .
   Next, we show that it suffices to prove the lemma when U and V are
disjoint. Let G = U ∩ V , U ′ = U \ G, and V ′ = V \ G. Note that
     m(U ′ ) = m(V ′ ) = c1 − m(G) and ν(U ′ ) ≤ c2 − ν(G) ≤ ν(V ′ ).
If we can find W ′ ⊂ U ′ ∪ V ′ such that m(W ′ ) = m(U ′ ) = m(V ′ ) and
ν(W ′ ) = c2 − ν(G), then W = W ′ ∪ G satisfies m(W ) = c1 and ν(W ) = c2 .
   Assume U and V are disjoint. Consider Ut = U ∩ [−t, t]. Let t0 =
sup{t ≥ 0 : m(Ut ) = 0}. For each t > t0 , there exists g(t) > 0 such
that m(V ∩ [−g(t), g(t)]) = m(Ut ). Define Vt = V \ [−g(t), g(t)] and let
Wt = Ut ∪ Vt . We have m(Wt ) = 1 for all t, and ν(Wt ) → ν(V ) as t → t0
and ν(Wt ) → ν(U ) as t → ∞. Since the function t 7→ ν(Wt ) is continuous,
the lemma follows from the Intermediate Value Theorem.                  □

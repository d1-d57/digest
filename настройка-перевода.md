# Бесплатный LLM-перевод: Safari + MacWhisper

Одна регистрация закрывает обе задачи. Карта нигде не нужна.

---

## Шаг 0. Бесплатный ключ Gemini (5 минут, делается один раз)

1. Открыть <https://aistudio.google.com>
2. Войти обычным Google-аккаунтом
3. В левом меню — **Get API key** → **Create API key**
4. Скопировать ключ, положить в заметки или Keychain. Показывается он один раз.

Карта не требуется, срок действия бессрочный.

**Что доступно бесплатно** (Pro-модели с апреля 2026 только платные):

| Модель | Запросов/мин | Запросов/сутки |
|---|---|---|
| `gemini-2.5-flash` | 10 | 250 |
| `gemini-2.5-flash-lite` | 15 | 1000 |
| `gemini-3-flash-preview` | ~10 | ~250 |

**Возможная засада:** в EEA, Великобритании и Швейцарии Google требует включить биллинг даже под бесплатные модели. И сам AI Studio доступен не из всех регионов. Проверяется за минуту на шаге 1 — если ключ выдался, всё хорошо. Если нет — план Б внизу.

## Задача 1. Перевод статей в Safari

### 1.1 Установка расширения

1. Mac App Store → искать **Immersive Translate for Safari**
   Прямая ссылка: <https://apps.apple.com/us/app/immersive-translate-for-safari/id6447957425>
2. Нажать **Get** — расширение бесплатное. Нужна macOS 12.0 или новее.
3. Safari → **Настройки** → **Расширения** → включить галочку у Immersive Translate
4. Там же нажать **Разрешить доступ ко всем сайтам** → выбрать **Всегда разрешать** (Always Allow).
   Без этого расширение не увидит страницу.

### 1.2 Подключить Gemini как движок

1. Открыть настройки расширения (иконка в панели Safari → шестерёнка, либо `immersivetranslate.com/options`)
2. Раздел **Translation Services** (Сервисы перевода)
3. Найти в списке **Gemini** → вставить ключ из шага 0 → выбрать модель `gemini-2.5-flash`
4. Поставить Gemini движком по умолчанию
5. Проверить на любой статье Quanta

### 1.3 Настройки, которые стоит поменять сразу

- **Двуязычный режим** — перевод абзацем под оригиналом. Главная причина брать это расширение: когда фраза выходит корявой, английский рядом, и ты не спотыкаешься.
- **Число абзацев в одном запросе** — поднять до 8–10. Бесплатный лимит считается в запросах, а не в тексте, поэтому крупные пачки экономят суточную квоту в разы. Со стандартными настройками страница съедает 20–40 запросов из 250.
- **Целевой язык** — русский.
- **Системный промпт** (раздел AI-промптов) — сюда идёт математический глоссарий и правило «заголовок адаптируем, а не переводим буквально». Пишется отдельно, когда базовая связка заработает.

### План Б, если ключ Gemini не выдался

OpenRouter: регистрация по email, без карты, модели с суффиксом `:free`.
В Immersive Translate — внизу списка сервисов **Add Custom AI Translation Service compatible with OpenAI interface**:

- Endpoint: `https://openrouter.ai/api/v1/chat/completions`
- Model: любой из списка `:free`

Ограничение: 50 запросов в сутки при нулевом балансе. С пачками по 10 абзацев это 5–8 статей в день. Терпимо, но хуже Gemini.

## Задача 2. MacWhisper без платного ключа

Сначала важное разделение: **сама транскрипция в MacWhisper локальная и бесплатная** — модели Whisper крутятся на твоём Mac. Ключ нужен только для AI-постобработки, то есть для превращения потока надиктовки в оформленный текст. Ровно то, чего тебе сейчас не хватает.

MacWhisper умеет работать с OpenAI, Anthropic, **Google Gemini**, Groq, DeepSeek, xAI, **OpenRouter**, **Ollama**, LM Studio и произвольным OpenAI-совместимым endpoint. Значит бесплатный ключ подходит напрямую.

### Вариант А — тот же ключ Gemini (проще)

1. MacWhisper → **Settings** → раздел AI / Prompts
2. Провайдер: **Google Gemini**
3. Вставить ключ из шага 0, модель `gemini-2.5-flash`

Постобработка диктовки — это короткие тексты по несколько сотен токенов. 250 запросов в сутки означает 250 надиктовок в день. Твои прежние 10 долларов за полтора месяца в такие лимиты укладываются с большим запасом.

### Вариант Б — Ollama локально (бесплатно совсем и без лимитов)

1. Поставить Ollama: <https://ollama.com/download>
2. В терминале: `ollama pull qwen3:8b` (или `gemma3:12b`, если оперативной памяти 24 ГБ и больше)
3. MacWhisper → Settings → AI → провайдер **Ollama** → выбрать модель

Плюсы: ноль лимитов, ноль трафика, всё остаётся на машине. Минус: модель на 8B слабее Gemini Flash, и Mac будет греться. Для чистки надиктовки этого обычно достаточно — задача механическая.

**Рекомендация:** начать с варианта А, он делается за две минуты на уже готовом ключе. Ollama — если упрёшься в суточный лимит или захочешь полной автономности.

## Почему это не заход для Claude Code

Здесь нечего автоматизировать: установка из Mac App Store, вход в Google-аккаунт, галочки в настройках Safari. Всё это GUI и авторизация, агент туда не дотянется. Инструкция выше — правильный формат.

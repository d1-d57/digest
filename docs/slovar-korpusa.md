# Эталонный словарь — обороты «объект + предикат» из ПРИНЯТЫХ выпусков

## 🔴 ПРЕДМЕТ ЭТОГО СЛОВАРЯ — ОБОРОТЫ ПРИ МАТЕМАТИЧЕСКИХ ОБЪЕКТАХ

Решение владельца 2026-08-16, и оно действует раз и навсегда: **предмет — нейрослоп в
МАТЕМАТИЧЕСКОЙ терминологии.** Оборот сюда попадает, если хотя бы одно его слово — математический
объект: граница, оценка, метод, гипотеза, теорема, доказательство, задача, функция, группа,
размерность, показатель, конструкция, контрпример. Бытовые штампы («впечатляющее открытие»,
«настоящий прорыв») — другой класс и другая, меньшая беда: их дом `slovar-stop.md` и общий редактор
русского, а не этот файл.

Число, на котором решение стоит: покрытие корпусом в выпуске 4 — 46 % при математических объектах и
1 % при бытовых словах. Корпус математической прозы про бытовое не знает ничего и не должен.

## 🔴 СТЕНД — `vypuski/pary_idiom.jsonl`. Постоянный инструмент проекта, не черновик одной пробы

Машиночитаемая половина этого файла: пары «незаконный оборот / законный оборот», каждая — одно
предложение в двух вариантах, различающихся только оборотом. На 2026-08-16 в нём 23 пары; число
снимается командой, а не переписывается отсюда:

```
python3 -c "import json;print(sum('id' in json.loads(l) for l in open('vypuski/pary_idiom.jsonl',encoding='utf-8')))"
```

**Зачем стенд существует.** Любой инструмент, претендующий на ловлю незаконной идиомы, меряется
на нём одним числом — «разделено X из N» — и сравнивается с уже замеренными. Базовая линия стоит:
классификаторы приемлемости RuCoLA дали 11, 14 и 10 из 23 при случайных 14 (`docs/DOLGI.md#Д27`).
Без стенда каждый новый кандидат обсуждался бы словами.

🔴 **ПОПОЛНЕНИЕ — ТОЛЬКО ВЕРДИКТОМ ВЛАДЕЛЬЦА, И СПРАШИВАТЬ НАДО ЯВНО.** Придумывать пары запрещено
ровно так же, как придумывать слова в `slovar-stop.md`. Поле `zamena_ot` у каждой пары говорит,
чей законный вариант: `vladelec` — из его разбора, `analitik` — реконструкция, вердиктом НЕ
подтверждённая. На 16.08 таких реконструкций 12 из 23, и это главная слабость стенда: он наполовину
меряет чужую интуицию. Решение владельца 2026-08-16: **каждый раз, когда он прошёлся по тексту и
назвал обороты, Cowork ОБЯЗАН спросить прямо — «какие из этих оборотов кладём в стенд, и какой
законный вариант вместо каждого».** Не спросил — стенд не растёт, и следующий замер снова наполовину
про интуицию аналитика. Носитель правила — `docs/fazy/stil.md`, шаг «пополнение стенда».

> **ЗАЧЕМ.** Русский математический язык — узкий набор устойчивых оборотов, каждый со своим
> смыслом, известным математикам. Синонимичная замена по правилам обычного русского незаконна,
> даже когда звучит естественно: «граница сдвинулась» можно, «граница ушла» нельзя.
> **Набор нельзя вывести из принципов — его можно только сверить с корпусом.** Этот файл и есть
> корпус.
>
> **ОТКУДА.** Выписано замером 16.08.2026 по 32 строгим блокам выпусков 02 (18 блоков) и 03 (14),
> которые владелец принял. Не придумано и не взято из учебника: канон матстатьи —
> «следовательно», «имеет место», «в силу», «тогда и только тогда» — в корпусе встречается **ноль**
> раз, и правило, построенное на нём, забраковало бы принятый материал.
>
> **КАК ПОЛЬЗОВАТЬСЯ.** Оборот из этого списка законен. Оборота нет в списке — это ещё не брак, но
> повод проверить по К14: называет ли предикат положение в наличной координатной системе или
> заводит рамку, которой в математике нет. Пополняется только новым принятым выпуском.

# Правила выпуска дайджеста (черновик — уточняем по ходу)

Как из пула (`materials.db`, проходящий слой) + текущего потока собирать номера. Это **выведенные правила, не жёсткий устав** — стартуем, смотрим, правим. Дом: `README.md` §«Следующие шаги» → этот файл.

## 0. Мета-критерий отбора — «математика, которая проясняет» (поверх 5 гейтов)

Над механикой пяти гейтов стоит один смысловой критерий (полная формулировка — `docs/O-PROEKTE.md`). Охотимся за материалом, после которого картина **не усложняется, а проясняется**: далёкие области оказываются одной, математика становится проще и цельнее. Гора честных работ, достраивающих общее здание, — не наш жанр; наш — редкий случай, когда становится **яснее**.

Живёт это прояснение обычно **не в самом результате, а в экспозиции вокруг** него: обзоре, монографии, пленарной лекции, научпопе, подкасте, интервью — от академических форматов до Quanta, нередко в видео, а не в тексте.

Как это направляет отбор:

- **Междисциплинарность (G1) — частный случай прояснения**, а не отдельная цель. Мост между областями = одна из форм единства математики; «мост-не-анонс» (G2) читаем туда же: анонс внутри подполя картину усложняет, прояснение — стягивает.
- **Экспозиция весит.** При прочих равных перевешивает сильная обзорная / лекционная / разговорная подача (survey, пленарка, монография, интервью-манифест), а не голый препринт.
- **Отсюда и ритм:** на неделю по-настоящему проясняющего не набирается, на две — вполне (§2).

Открытый вопрос (решаем с владельцем, не финал): вводить ли явный тег «прояснение» (да / нет / сильно) в разметку базы и не перевесить ли композит в сторону G1 + значимости экспозиции. Пока держим как **редакторский мета-критерий поверх формулы**, скоринг базы не трогаем.

## 1. Принцип актуальности — «news peg» (живой повод)

Материал входит в дайджест не потому, что «недавний по контенту», а потому что есть **живой повод рассказать сейчас**. Два рода повода:

- **Собственная свежесть** — только что вышло (Quanta, свежий блог-разбор, объявленный результат). Протухает за 1–2 недели.
- **Событийный повод** — что-то случилось (премия, книга, юбилей, смерть, конференция). Лагает законно — новость это факт события, а не возраст материала.

Нет живого повода (статья 1992-го, вечная экспозиция про Гротендика) → **в дайджест не идёт** (в канал — можно). Это и есть граница «почему не всё за год».

**Два подтипа по «скорости протухания»:**
- **Мягко-пеговые** (Snapshots, экспозиции, лекции ЛШСМ/коллоквиумов, книги, обзоры) — не протухают, могут ждать в очереди недели, даже месяц. Это шок-абсорбер, заполняющий тонкие недели.
- **Жёстко-пеговые** (свежая Quanta, только объявленный прорыв) — ждать не могут: либо в ближайший номер, либо в канал.

## 2. Ритм

- **Старт — раз в 2 недели.** Июль–август ≈ 4 выпуска. Фиксированный слот (предпочтительно суббота — предсказуемость = привычка подписчика).
- **Пропуск, а не натягивание.** Период тонкий (<3 свежепеговых) → слот пропускаем (лето, затишье). Лучше пропустить, чем выпустить слабое.
- **Переход на еженедельно — по факту, не заранее.** Многое не протухает быстро (ЛШСМ выкладывает записи постепенно, лаг 2–4 недели нормален), поэтому недельная рассылка со временем будет набираться. Ориентир пересмотра — сентябрь: если начнёт переливаться (материал не влезает) — переходим на неделю. Вперёд жёстко не закладываемся.

## 3. Размер выпуска

- **Кап ~5–6 материалов, жёстко.** Никаких 13. Отбор — по композиту `score_total` + редакторское чутьё владельца.
- **Перелив:** мягко-пеговые сверх капа → в очередь на следующий выпуск; жёстко-пеговые сверх капа → в канал (ждать не могут).

## 4. Очередь-буфер (копится вперёд)

Из мягко-пеговых, что не влезли. **Честный буфер** — накапливается по ходу выпусков, не выкапывается задним числом из года. Здоровый выпуск = пара свежих новостей недели + добор из очереди до ~5–6.

## 5. Баланс выпуска (мягкие правила при сборке)

- **Quanta ≤ ~25% выпуска** — не превращать в пересказ Quanta (в пуле сейчас Quanta 28%, поэтому кап на сборке важен).
- **Тематический дедуп:** один результат = один слот, лучший формат (напр. Кэкейя лежит в 3 форматах — Snapshot/Бурбаки/JMM — берём один). Не только url/title.
- **Разнообразие:** стараться ≤2 материала из одного раздела; подтягивать тонкие (дифгео / представления / динамика), когда есть.
- **≤1 некролог на выпуск.**

## 6. Единица выпуска

Заголовок (оригинальный) + ссылка + **абзац-осмысление по-русски** — что это и почему интересно широкому математику (из `read_note`, развёрнутого до абзаца). Образец голоса — `primer-vypuska.html`.

## 7. Формат доставки

- **Пока — просто в канале** «Кроссворд Тьюринга» (не бот). Богатый выпуск в одно Telegram-сообщение не влезает → короткий тизер + ссылка на **онлайн-страницу выпуска** (вёрстка как `primer-vypuska.html`).
- **Бот — позже**, когда перерастём ручной режим.

## 8. Дайджест vs канал

- **Дайджест** — пегованная актуальность, систематично, по расписанию.
- **Канал** — твой голос на чём угодно; вечное можно.
- Непегованные жемчужины пула (Гротендик; декабрьский Концевич–Кацарков) — **резерв контента для канала**, не для дайджеста. Ничего не пропадает.

## 9. План запуска (июль–август 2026)

| Выпуск | Когда | Повод / содержание |
|---|---|---|
| 1 | перед Конгрессом | обзор конца июня — начала июля (Snapshots, ЛШСМ-2025, Cook уже в пуле) |
| 2 | перед / на открытии ICM | 10 июля → открытие Конгресса |
| 3 | после ICM (~конец июля) | **ICM 2026 / Филдсовские медали — флагман** (крупнейший повод года) |
| 4 | 2-я половина августа | сателлиты ICM + записи ЛШСМ-2026 (выкладываются во 2-й половине августа) |

Сентябрь — пересмотр ритма по накоплению (возможен переход на еженедельно).

## 10. Открытый фронт (главная инвестиция)

**Шире закинуть невод.** Много высокосигнальных, но редких и труднодоступных источников мы ещё не нашли/не научились тянуть — там наверняка остались «бриллианты». Особый класс: **отдельные создатели, выдающие золото редко** (раз в полгода), например лауреатские YouTube-каналы с лекционными курсами. Их надо копить в **широкий watchlist** (не firehose, а курируемый список людей/каналов, проверяемый периодически). Это отдельный поток работы — брейншторм + discovery-заход. См. `docs/istochniki-kandidaty.md`.

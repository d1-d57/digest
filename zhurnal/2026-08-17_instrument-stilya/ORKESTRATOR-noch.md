### 2. 🔴 СНАЧАЛА ЗАКОММИТЬ КОМПЛЕКТ — ИНАЧЕ РАБОЧАЯ ПАПКА РОДИТСЯ ПУСТОЙ

**Это блокирующий шаг, и пропустить его нельзя.** Файлы, которыми ты работаешь, собраны из песочницы
Cowork, а она в `.git` писать не может — значит они лежат **неотслеживаемыми**. `worktree add`
переносит в новую папку только то, что git знает; неотслеживаемое остаётся. Заведёшь папку раньше —
окажешься в ней без единого файла-захода, без `RESHENIYA-o-skille.md` и без `NOCH/`.

```
git --no-optional-locks status --porcelain zhurnal/2026-08-17_instrument-stilya
git --no-optional-locks add -- zhurnal/2026-08-17_instrument-stilya docs/DOLGI.md zhurnal/_INFRA-git
git --no-optional-locks commit -m "arka-stil: ночная цепочка, решения владельца, ресёрч, замеры" -- zhurnal/2026-08-17_instrument-stilya docs/DOLGI.md zhurnal/_INFRA-git
git --no-optional-locks status --porcelain zhurnal/2026-08-17_instrument-stilya   # обязано быть ПУСТО
```

⚠ **`add` и `commit` с путями после `--` — обе половины обязательны.** Без `add` новые файлы не
попадут в индекс; без путей в `commit` он заберёт индекс целиком вместе с чужим — рядом работает
скачка Википедии, и её файлы в твой коммит попасть не должны.
⚠ Коммит не прошёл (чужой лок, хук) — **СТОП, дальше не иди**: без него вся ночь работает вхолостую.
Опиши причину и остановись; это законный отчёт.

### Как запускать заход

Каждый файл-заход самодостаточен: в нём контракт зоны, что читать, задача и критерий готовности.
Запускай подагентом (Task), передав ему ровно одно указание: прочитать свой файл целиком и работать
строго по нему, проект сверх названного не изучая. Модель — из таблицы выше.

🔴 **Ответ любого подагента обязан кончаться строкой «выдано N позиций из M найденных».** Канал мог
оборвать его молча, и без этой строки усечение неотличимо от честного «мало нашлось». Нет строки —
перезапроси, а не додумывай.

## ГИТ — В КОНЦЕ КАЖДОЙ ФАЗЫ, НЕ В КОНЦЕ НОЧИ

Каждый заход коммитит свою зону сам, последним ходом (это вшито в их файлы). Твоё дело — проверить,
что он это сделал:

```
git --no-optional-locks status --porcelain    # пусто по его путям
```

Не сделал — **разбираешь ТЫ, и вот как именно** (иначе цепочка встанет намертво, а ночью спросить
некого): посмотри `git status --porcelain`, и по каждому пути реши одно из двух. Путь входит в зону
упавшей фазы и её работа полезна — **коммить сам** её же сообщением, отметив в отчёте, что коммит
твой. Работа явно сломана или недоделана — **откати** `git checkout -- <путь>` и запиши, что
откатил. Не оставляй грязь и не жди: следующая фаза работает в той же папке и смешает своё с чужим.

В самом конце ночи: ветку `zahod/stil-noch` **не вливать и не гасить** — влитие решает владелец

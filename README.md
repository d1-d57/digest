# MATEMDIGEST · карта года

Карта жизнеспособности для еженедельной Telegram-рассылки материалов высокого уровня
по математике («Quanta для математиков»). Это **база кандидатов за скользящее окно 12 месяцев**
(`materials.db`), поверх которой наросли слои курирования — вплоть до **точно прочитанного проходящего слоя** —
+ визуальная карта (`karta-goda.html`) + реестр источников.

> **Это НЕ бот и НЕ рассылка.** Пока — карта и слой отбора. Сборка рассыльщика (буфер-очередь, вёрстка выпуска) — отдельный этап.

## Слои курирования (что накоплено поверх сбора)

Сырой сбор (738) — только фундамент. Поверх — слои, каждый своим заходом; сырьё не удаляется, курирование обратимо:

1. **ЗАХОД-1** — гигиена данных (масштхед-дроп, нормализация заголовков): 746 → 738.
2. **ЗАХОД-1b** — редакторская отбраковка контента: `keep`/`fitness`/`fit_reason` на всех 738 (346 годных).
3. **ЗАХОД-1c-cal** — числовая рубрика гейтов (5 ворот 0–3), выверена на 30 прочитанных текстах (Sonnet).
4. **ЗАХОД-1c-stat** — дешёвая (Haiku, по метаданным) статистическая доразметка всего года: сегментация + `score_total`. Приблизительно.
5. **ЗАХОД-1c-precise** — точное чтение полного текста годного слоя (Sonnet, 349 строк): финальные гейты, чистые разделы, русские описания. `scored_from='precise'`.

**Текущий проходящий слой:** `scored_from='precise' AND score_total≥10 AND g2_bridge≥1` = **222**. Это честная «Quanta для математиков» за окно.

Колонки курирования в `materials.db`: `keep/fitness/fit_reason` (1b); `g1_breadth..g5_extract`, `score_total`,
`areas_multi` (мульти-тег), `interdisc`, `read_note` (рус.), `content_read`, `scored_from` (`heur-out`/`meta`/`text`/`precise`), `areas_norm`.

## Гейты (рубрика отбора — 5 ворот, 0–3; заменяет старую эвристику score.py для курирования)

- **G1 · междисциплинарность / выход за пределы подполя** — мастер-ворота (причина существования рассылки).
- **G2 · мост, а не анонс** — единица = экспозиция мост-строителя, не сырой препринт/авторский тех-анонс.
- **G3 · понятность математической идеи** широкому слою (не лёгкость текста вообще).
- **G4 · значимость** результата / события / фигуры.
- **G5 · добываемость** (есть линкуемый мост).

Композит `score_total = 2·G1 + 2·G3 + G2 + G4` (0–18). **Порог прохода: `score_total ≥ 10 И G2 ≥ 1`.**
Таксономия `areas_multi` — 17 канонных разделов + `образование`; люди/книги/история несут раздел (область фигуры/предмета).

## Как собран сырой слой (механизм по категориям; историческое)

- **A · проф. журналы** — Crossref REST по ISSN (`/journals/{ISSN}/works`, polite pool). Логика в `pull_surveys.py`.
- **C · научпоп** — Quanta через `www.quantamagazine.org/wp-json/wp/v2/posts`; plus.maths и AMS Feature Column — RSS.
- **D · блоги** — годовой охват через WordPress REST (RSS отдаёт лишь 5–25 последних — на год не хватает).
- **B · обзорные площадки** — скрейп bourbaki.fr, ICM 2026, JMM CEB, Takagi (`data/b_venues.json`).
- **E · разовое/люди/события** — премии/книги/юбилеи (`data/e_*.json`), YouTube (RSS по channel_id).

Пайплайн сбора: `fetch_*` → нормализация → дедуп (url+title) → фильтр окна → junk-дроп → классификация → `materials.db`.
Перезапуск на новом окне — две константы (`FROM`/`UNTIL`) в `config.py`, затем `python3 build.py`.

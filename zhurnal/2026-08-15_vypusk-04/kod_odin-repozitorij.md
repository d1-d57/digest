## ЗАДАЧА — девять шагов по порядку

**1. Бэкап.** Одна команда, тридцать секунд, дальше идут необратимые вещи:

`echo $?` → 0. Путь назови в отчёте.

**2. Снять мёртвый лок.** `git_zona.py clean`. В `.git` лежит `index.lock` месячной давности — пока он там, запись не пройдёт.

**3. Выкинуть мусор среды из индекса.** `git_zona.py untrack --yes`. Снимет с индекса то, что попало под `.gitignore`: 21 файл `.fuse_hidden*` (артефакты песочницы), `.DS_Store`, `materials.db-shm`, `materials.db-wal`. Файлы на диске остаются.

**4. Закоммитить месяц работы — двенадцать коммитов.**
`git_zona.py plan` соберёт черновик `_studio/.commit-plan`. Перепиши в нём сообщения по таблице §4 заявки, затем `git_zona.py commit` (без `--push` — origin ещё нет).
⚠ `==` — это ПРЕФИКС строки-сообщения, не заглушка: строка обязана начинаться с `== `, меняется текст после него.
⚠ Двенадцать — раскладка по смыслу, не обязательство. Файл появился или переехал после сборки захода — разложи иначе и скажи в отчёте, что куда. Брак — не «вышло одиннадцать», а «путь не попал ни в один коммит, и это не названо».

**5. Завести origin и развести ветки.**
```
git --no-optional-locks branch -m main rabota
git --no-optional-locks remote add origin https://github.com/d1-d57/digest.git
git --no-optional-locks fetch origin
git --no-optional-locks branch main origin/main
```
`branch -m` переименовывает, дерева не трогает. `main` теперь витрина, взятая с origin. Две истории без общего предка в одном репозитории — это нормально, **сливать их между собой не надо и не пытайся**.

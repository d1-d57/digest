# vypuski/ — архив выпусков MATEMDIGEST

Здесь живёт весь архив выпусков дайджеста — **папка на каждый выпуск**, помеченная датой выхода. Принцип, как в `materials/_generator`:

> **Markdown — источник истины. HTML и Telegram — только виды.**
> Правишь текст в одном месте (`vypusk.md`) — пересобираются оба вида.

## Структура

```
vypuski/
  build_vypusk.py            ← общий движок (один на все выпуски)
  README.md                  ← этот файл
  2026-07-11-vypusk-01/      ← папка выпуска (по дате выхода)
    vypusk.md                ← ИСТОЧНИК. Только его правишь руками.
    vypusk.html              ← страница (генерится): смотреть + хостить
    vypusk.telegram.txt      ← пост в канал (генерится)
    vypusk.teaser.txt        ← короткий тизер + ссылка (генерится, если пост >4096)
  2026-07-25-vypusk-02/      ← следующий выпуск
    ...
```

Папка выпуска — это его архив: источник, страница, пост. Сюда же со временем лягут доп-материалы выпуска (например, отдельный анонс-пост, если будем вести его руками).

## Сборка

```bash
cd vypuski
python3 build_vypusk.py 2026-07-11-vypusk-01/vypusk.md          # линтер + собрать три вида
python3 build_vypusk.py 2026-07-11-vypusk-01/vypusk.md --lint    # только проверить структуру
```

Движок — чистый Python (stdlib), без сети/pip/токенов. Перед сборкой **линтер-гейт**: структурная ошибка (нет ссылки, нет подводки, кривая дата) → сборка прерывается и показывает, что чинить. Печатает длину Telegram-поста и влезает ли он в 4096; не влезает → постим `vypusk.teaser.txt` (тизер + ссылку на страницу), как в `../docs/pravila-vypuska.md`, раздел «Формат доставки» (первый §7).

## Формат источника `vypusk.md`

Фронтматтер (между `---`) + лид-абзац + **рубрики** (H1, `# Рубрика`) с карточками (H2, `## Заголовок`):

```markdown
---
number: 1
title: MATEMDIGEST
subtitle: Обзор за две недели · конец июня — начало июля 2026
date: 2026-07-11
channel: Кроссворд Тьюринга
channel_url: https://t.me/turings_crossword
page_url: https://matemdigest.ru/1      # ссылка в тизере
teaser: одна строка для короткого поста…
---

Лид-абзац выпуска (любой текст до первой рубрики).

# Новые результаты
## Заголовок материала по-русски
- url: https://…
- source: Quanta Magazine
- byline: Лейла Сломан             # автор — выводится вперёд
- date: 2026-06-26
- areas: комбинаторика · вероятность · геометрия
- kind: статья                    # жанр — крупный чип: статья/блог/обзор/подкаст/интервью/видео

Абзац-подводка: что это и почему интересно широкому математику.
Инлайн: **жирный**, *курсив*, `код`, [ссылка](https://…), математика — $n^{4/3}$, $n^{1+o(1)}$.

# Обзоры
## …
```

Обязательные поля карточки: `url, source, date, areas, kind`. `byline` — опционально. Заголовок — строка после `##`. Рубрики и карточки идут **в том порядке, в каком стоят в файле** (движок не сортирует): аранжировка на авторе — статьи выше, видео в конец.

## Завести новый выпуск

1. Создать папку `ГГГГ-ММ-ДД-vypusk-NN/` (дата выхода).
2. Скопировать в неё `vypusk.md` от прошлого выпуска, поменять `number`, `subtitle`, `date`, `teaser`, `page_url` и карточки.
3. `python3 build_vypusk.py ГГГГ-ММ-ДД-vypusk-NN/vypusk.md`.

Правила отбора и ритма — `../docs/pravila-vypuska.md`. Концепция проекта — `../docs/O-PROEKTE.md`. Голос — русский редактор без канцелярита и пафоса.

## 3. Сообщения коммитов

Четыре группы. Форма — `== сообщение`, дальше пути; `==` остаётся, меняется текст после него.

```
== интервью Вязовской: перевод февральской части и генератор одностраничника
build_intervyu.py
Vyazovskaya-intervyu-2022-perevod.md
Vyazovskaya-intervyu-2022-perevod.html
sayt/static/vyazovskaya/index.html

== корпус вики: сырьё в git не идёт, коммитится только порождённая таблица
.gitignore

== словарь корпуса: рамка задачи словами владельца 17.08 — карта замен, а не список подозрений
docs/slovar-korpusa.md

== заход по корпусу: шаг 6, срезы корпуса — дописано под работающим исполнителем
zhurnal/2026-08-15_vypusk-04/kod_korpus-wiki.md
```

Если к моменту старта вне git окажется что-то ещё — **дописать группу, а не подмести чужое в
существующую**. Не понимаешь, чья правка и зачем, — назови её отдельной группой с честным
сообщением «правка появилась между заявкой и заходом, автор не установлен», а не молчи.

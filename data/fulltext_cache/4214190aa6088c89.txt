                                                                                  Abstract
                                                   Let fr (x) = log(1 + rx)/ log(1 + x) for x > 0. We prove that fr is
                                                a complete Bernstein function for 0 ≤ r ≤ 1 and a Stieltjes function for
                                                1 ≤ r. This answers a conjecture of David Bradley that fr is a Bernstein
                                                function when 0 ≤ r ≤ 1.

                                           tion, Pick function.

    Bernstein functions are by definition C ∞ -functions f : (0, ∞) → [0, ∞) satis-
fying
                    (−1)n−1 f (n) (x) ≥ 0, x > 0, n = 1, 2, . . . .            (2)
In particular, Bernstein functions are non-negative, increasing and concave. To
verify the inequalities (2) for fr seems a complicated task, because one has to
differentiate a quotient. We prove instead the stronger statement, that fr belongs
to the subclass CBF of complete Bernstein functions studied in [8]. Our proof
uses complex analysis.
    Bernstein functions have a long history, and they play an important role in
probability theory and potential theory, see [8] and [1].

2    Preliminaries about Pick functions
Let H := {z ∈ C | ℑz > 0} denote the open upper half-plane.
   A holomorphic function f : H → C is called a Pick function if its imaginary
part ℑf (z) ≥ 0 for all z ∈ H.
   For a Pick function f , ℑf is a non-negative harmonic function, and it has the
mean value property. It is therefore either identically zero or strictly positive on
H. This means that a Pick function is either a real constant function or it maps
H into itself. Pick functions are treated in [5], [8] and in the Appendix to [9].

5      A question answered in the negative
Since f (x) = log(1 + x) is a complete Bernstein function, it is a natural question
if the following extension of Theorem 1 holds:
                f ∈ CBF =⇒ f (rx)/f (x) ∈ CBF when 0 < r < 1.
We shall see that the answer to this question is negative.
    First notice that if such an implication holds, then necessarily f (0) = 0,
for otherwise letting r → 0 we would obtain 1/f (x) ∈ CBF , and under the
assumption f ∈ CBF this is only possible, when f is constant.
    A counterexample to the implication is obtained, when f (x) = x/(x + 1) +
x/(x + 3) which is a complete Bernstein function. A small calculation shows that
          f (x/4)    (x + 1)(x + 3)(x + 8)     3/10   3/4   99/20
                  =                        =1−      −     −       .
           f (x)    (x + 2)(x + 4)(x + 12)     x + 2 x + 4 x + 12
Since we have negative coefficients in the partial fraction decomposition, the
conclusion is that the function f (x/4)/f (x) ∈
                                              / CBF .

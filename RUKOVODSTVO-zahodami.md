## Грабли (каждая — реальный инцидент, не гипотеза)

2. **Никаких `rm -rf` в чистке заходов — откатывай точечно.** Тот же инцидент: откат нарушения через `rm -rf vypuski/` снёс папку, которую параллельно легитимно создал аналитик (пути совпали). Удаляй поимённо / `git checkout <файл>`, не сноси каталоги целиком.

3. **Не гонять мутирующий заход в фоне, пока аналитик правит те же пути.** Конкурентная работа по одним путям = потеря работы. Либо аналитик дожидается завершения захода, либо заход и аналитик разведены по разным зонам файловой системы.

4. **Git-запись из Cowork-песочницы не работает.** `.git` смонтирован через fuse и запрещает запись (объекты и локи) → `commit`/`add`/`reset` падают с «Operation not permitted» и оставляют stale-локи, которые из песочницы не снять. **Версионирование — только локально у владельца.** Перед локальным коммитом снять зависшие локи: `rm -f .git/index.lock .git/HEAD.lock .git/refs/heads/main.lock`. Файлы-результаты писать в рабочее дерево можно как обычно — это работает.
